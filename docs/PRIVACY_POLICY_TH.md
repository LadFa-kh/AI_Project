# นโยบายความเป็นส่วนตัว (ร่าง) — ResuMate

> **สถานะ: ร่างสำหรับทบทวน** เขียนจากข้อมูลที่ระบบเก็บจริงตามโค้ด ณ วันที่ 24 ก.ย. 2569
> ผู้รับผิดชอบโครงงานต้องอ่านและแก้ไขก่อนเผยแพร่ และควรให้อาจารย์ที่ปรึกษาตรวจ เอกสารนี้ไม่ใช่คำแนะนำทางกฎหมาย
> ช่องที่อยู่ใน [วงเล็บเหลี่ยม] ต้องเติมเอง

**เวอร์ชัน:** 1.0  **มีผลตั้งแต่:** 24 กันยายน 2569

## 1. ผู้ควบคุมข้อมูล
ระบบ ResuMate (https://app.recommendation.site) เป็นโครงงานของนักศึกษาสาขาวิศวกรรมคอมพิวเตอร์ มหาวิทยาลัยเทคโนโลยีราชมงคลอีสาน วิทยาเขตขอนแก่น
ติดต่อเรื่องข้อมูลส่วนบุคคล: [อีเมลติดต่อ]

## 2. ข้อมูลที่เราเก็บ
| ประเภท | รายละเอียด |
|---|---|
| ข้อมูลบัญชี | อีเมล ชื่อ-นามสกุล เบอร์โทรศัพท์ (ถ้ากรอก) รหัสผ่านที่เข้ารหัสแล้ว (เราไม่เห็นรหัสผ่านจริง) และรหัสบัญชี Google กรณีเข้าสู่ระบบด้วย Google |
| เรซูเม่ | ไฟล์ PDF ที่อัปโหลด และทักษะที่ระบบสกัดได้จากเรซูเม่ |
| ผลการประเมิน | คำตอบแบบประเมินตนเอง คะแนนเรซูเม่ คะแนนแบบประเมิน คะแนนรวม ตำแหน่งงานที่สนใจ และคำแนะนำที่ระบบสร้าง |
| ประวัติฝึกงาน | บริษัท ตำแหน่ง ช่วงเวลา ชื่อและอีเมลผู้ดูแลการฝึกงาน และบันทึกที่ผู้ใช้หรือบริษัทกรอก |
| ข้อมูลบริษัท (ผู้ประกาศงาน) | ชื่อบริษัท เลขประจำตัวผู้เสียภาษี ที่อยู่ ช่องทางติดต่อ และประกาศงาน |
| บันทึกการใช้งาน | ประเภทการใช้งาน (อัปโหลดเรซูเม่ / ส่งแบบประเมิน) เวลา ผลสำเร็จ เครดิตที่ใช้ และปริมาณการประมวลผลของ AI |
| บันทึกความยินยอม | เวอร์ชันนโยบายที่ยอมรับ เวลาที่ยอมรับหรือถอน หมายเลข IP และข้อมูลเบราว์เซอร์ (User-Agent) ขณะยอมรับ |
| คุกกี้ | คุกกี้ `accessToken` สำหรับยืนยันตัวตนเท่านั้น (HttpOnly อายุ 1 วัน) ไม่มีคุกกี้โฆษณาหรือติดตาม |

## 3. วัตถุประสงค์
1. ยืนยันตัวตนและให้บริการบัญชีผู้ใช้
2. วิเคราะห์เรซูเม่ ประเมินทักษะ และแนะนำสายงานและสถานประกอบการที่เหมาะสม
3. ให้ผู้ประกาศงานลงประกาศ และให้ผู้ดูแลระบบอนุมัติผู้ประกาศงาน
4. จำกัดการใช้งาน (เครดิต) ป้องกันการใช้งานผิดวัตถุประสงค์ และคำนวณค่าใช้จ่ายของระบบ
5. เก็บหลักฐานการให้ความยินยอมตาม พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562

## 4. การส่งข้อมูลให้บุคคลภายนอก
- **ผู้ให้บริการ AI:** ข้อความที่อ่านได้จากเรซูเม่และทักษะ ถูกส่งไปประมวลผลผ่าน CometAPI ไปยังโมเดล Google Gemini เพื่อสกัดทักษะ สร้างแบบประเมิน และสร้างคำแนะนำ [ตรวจสอบนโยบายการเก็บข้อมูลของผู้ให้บริการ]
- **Cloudflare:** ใช้เป็นช่องทางเชื่อมต่อแบบเข้ารหัส (HTTPS) ระหว่างผู้ใช้กับเซิร์ฟเวอร์
- เราไม่ขายหรือให้ข้อมูลแก่บุคคลภายนอกเพื่อการตลาด

## 5. ระยะเวลาเก็บรักษา
| ข้อมูล | ระยะเวลา |
|---|---|
| บัญชี เรซูเม่ ผลการประเมิน ประวัติฝึกงาน | จนกว่าผู้ใช้จะลบบัญชี |
| บันทึกการใช้งาน | 365 วัน แล้วลบอัตโนมัติ (เมื่อลบบัญชี จะตัดความเชื่อมโยงกับบัญชีทันที เหลือไว้เป็นสถิติที่ไม่ระบุตัวตน) |
| บันทึกความยินยอม | จนกว่าผู้ใช้จะลบบัญชี |
| ประกาศงาน | ยังคงอยู่หลังผู้ประกาศลบบัญชี แต่ไม่เชื่อมโยงกับบัญชีนั้นแล้ว |

## 6. สิทธิ์ของผู้ใช้
| สิทธิ์ | วิธีใช้สิทธิ์ |
|---|---|
| ขอดู / ขอสำเนาข้อมูล | ปุ่ม "ดาวน์โหลดข้อมูลของฉัน" ในหน้าตั้งค่าบัญชี (ไฟล์ JSON) |
| ขอลบข้อมูล | ปุ่ม "ลบบัญชี" ในหน้าตั้งค่าบัญชี ระบบจะลบบัญชี เรซูเม่พร้อมไฟล์ ผลการประเมิน ประวัติฝึกงาน และบันทึกความยินยอม |
| ถอนความยินยอม | ในหน้าตั้งค่าบัญชี (เมื่อถอนแล้ว ต้องยอมรับนโยบายใหม่ก่อนใช้งานต่อ) |
| ขอแก้ไขข้อมูล / คัดค้าน / ร้องเรียน | ติดต่อ [อีเมลติดต่อ] หรือร้องเรียนต่อสำนักงานคณะกรรมการคุ้มครองข้อมูลส่วนบุคคล |

## 7. ความปลอดภัย
รหัสผ่านเข้ารหัสด้วย BCrypt การเชื่อมต่อเข้ารหัสด้วย HTTPS คุกกี้ยืนยันตัวตนเป็นแบบ HttpOnly ฐานข้อมูลไม่เปิดให้เข้าถึงจากอินเทอร์เน็ต และจำกัดจำนวนครั้งการเข้าสู่ระบบเพื่อป้องกันการเดารหัสผ่าน

## 8. การเปลี่ยนแปลงนโยบาย
เมื่อมีการแก้ไขนโยบาย เวอร์ชันจะเปลี่ยน และระบบจะขอให้ผู้ใช้ยอมรับนโยบายฉบับใหม่ในการเข้าใช้งานครั้งถัดไป
